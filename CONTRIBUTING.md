# Contributing to awesome-llm-benchmarks

Thank you for wanting to make this list better.

## What belongs here

- **Benchmarks** — publicly released, with a paper / repo / docs.
- **Evaluation frameworks** — open-source tools for running benchmarks.
- **Leaderboards** — continuously updated public rankings.
- **Papers on benchmark quality** — foundational references on evaluation methodology.

## What doesn't belong here

- Proprietary leaderboards with no public methodology.
- Benchmarks without a public dataset or reproducible protocol.
- Duplicates of existing entries.
- Benchmarks that have been widely shown to be saturated or contaminated, unless listed with a caveat.

## How to add an entry

1. Fork this repo.
2. Add the entry in the most-appropriate section, keeping the existing alphabetical (or logical) ordering.
3. Follow the format: `- [Name](link) — short one-line description.`
4. Submit a PR with a descriptive title (e.g., "Add FooBench to Agentic section").
5. In the PR description, link to the paper, repo, or leaderboard.

## How to propose a new section

Open an issue first. Sections should be differentiated by evaluation *purpose*, not by model family.

## Style

- Prefer the **official repository** link over a mirror.
- Descriptions should state **what** the benchmark measures and **why** it matters (or is distinctive).
- No marketing language. No superlatives.
- Keep descriptions to a single line.

## Code of Conduct

Be respectful. Attacks on other projects, authors, or researchers are not welcome. If you disagree with a benchmark's methodology, open an issue for discussion rather than editing descriptions unilaterally.
